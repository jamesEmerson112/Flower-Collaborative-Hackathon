An **arm** includes the structural links and joints. A **torso** is a body frame
or shell; an empty shell is explicitly labeled. **Whole robots** are references
and complete-system purchases, not separately orderable torsos. Bare motors,
servos, electronics, sensors and wheels are component categories in the original
database. Prices retain their currencies; blank means no verified public price.
CAD links may be source repositories or gated downloads. A source link does not
mean that a complete assembled mesh is ready; check `browser_ready` separately.
